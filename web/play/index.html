❖ 游戏说明

玩法：选择世界与角色形象后进入案件。点击选项推进故事，也可以随时在底部的对话框中输入自己的行动或台词（回车发送）。试玩版内置 3 个世界共 6 桩案件（古老宅邸 / 迷雾港 / 霓虹街区，其中「冰痕」和「最后一帧」是为本作四个核心玩法专门写的那两桩），正式版将包含 8 个世界共 16 桩案件。

❄ 冰融倒计时：每桩案七天。第 1-3 天冰面完整，物证可采集；第 4-6 天冰层开裂，标注了融解日的证据会不可逆地消失；第 7 天冰面全化，留在冰上没来得及鉴定的物证一律捞不上来，你只能基于手里保住的证据做最终推演。每一次选择都意味着放弃。

🔬 物证鉴定：鉴定不可逆，而且一天只做得了两件——鉴定台只有一双手，跨天才重新排得下。抢在融解日之前把它做成铁证，才谈得上上推理板。

🧩 证据链拼合：点「推理板」，把物证卡、证词卡、时间线卡两两连线。互相矛盾的两条会把链条当场扯断；只有让一组材料全部接成一条不断的链，那条推断才站得住。

🤝 信任博弈：嫌疑人档案里每个人都有自己的耐心与信任。施压能撬出口供和物证，但耐心归零就会永久封存他手里所有还没上板的材料；共情慢，却能让你听到他只在信任时才肯说的话；沉默不花时间，是什么也换不到。你选择信任谁，决定了哪些证据会出现在推理板上。

🚪 多线结局：同一桩案有 7 个结局，由「你保住了哪些证据」「闭合了哪条命题」「指控了谁」「把谁逼到了封口」共同决定。结案后可以「承办下一案」，等级、金币与羁绊会跟着你走进下一份卷宗。

数值：战斗与探索会改变 HP / 攻防 / 金币 / 经验，经验满级自动提升。HP 归零即冒险终结。

剧情语音：点击对话框上的 🔊，剧情将以配音形式朗读——旁白用你选的声线，每个角色拥有自己的固定声线（按气质自动分配），台词还带情绪语气（愤怒、低语、悲伤……语速音调随之变化）；播放时对话框标题会显示当前发声者。下方「旁白声线」可更换旁白音色，选择会被记住。

界面主题：默认「档案卷宗」——纸张颗粒、打字机字体、冷色调；也可在菜单或游戏内切换回早期的「霓虹夜色」主题，选择会被记住。

倍速与暂停：对话框下方可切换剧情倍速（1× / 1.5× / 2× / 3×），文字与语音同步变速；点「暂停」或按空格键可随时暂停、继续。

音乐与音效：进入时点击「▶ 点击开始」即会自动播放黑色侦探氛围 BGM 与启动音效。播放旁白时音乐会自动压低，说完即恢复。

存档：游戏内点「存档」保存在浏览器本地，「继续冒险」可读取。

离线模式：未配置 API Key 时仍可体验内置剧情。

战斗与运气：遇到敌人时弹出战斗面板，可攻击 / 防御 / 施放技能（耗 8 法力）/ 喝药水 / 逃跑；攻击附带「运气骰」判定，暴击与闪避取决于你的运气属性，另有「🎲 命运骰子」可搏一次扭转战局的机会。

羁绊 · 商店 · 成就：右下「羁绊」查看与同伴（如陆沉）的默契；「商店」花金币强化属性、买药水；「成就」收录 26 枚徽章。默契、金币、等级、成就都会计入结局评级（S/A/B/C）。
