❖ 游戏说明

玩法：选择世界与职业后进入案件。点击选项推进故事，也可以随时在底部的对话框中输入自己的行动或台词（回车发送）。试玩版内置 2 个世界的完整案件（古老宅邸 / 迷雾港），正式版将包含 8 个世界共 16 桩案件。

数值：战斗与探索会改变 HP / 攻防 / 金币 / 经验，经验满级自动提升。HP 归零即冒险终结。

剧情语音：点击对话框上的 🔊，剧情将以配音形式朗读——旁白用你选的声线，每个角色拥有自己的固定声线（按气质自动分配），台词还带情绪语气（愤怒、低语、悲伤……语速音调随之变化）；播放时对话框标题会显示当前发声者。下方「旁白声线」可更换旁白音色，选择会被记住。

界面主题：默认「档案卷宗」——纸张颗粒、打字机字体、冷色调；也可在菜单或游戏内切换回早期的「霓虹夜色」主题，选择会被记住。

倍速与暂停：对话框下方可切换剧情倍速（1× / 1.5× / 2× / 3×），文字与语音同步变速；点「暂停」或按空格键可随时暂停、继续。

音乐与音效：进入时点击「▶ 点击开始」即会自动播放黑色侦探氛围 BGM 与启动音效。播放旁白时音乐会自动压低，说完即恢复。

存档：游戏内点「存档」保存在浏览器本地，「继续冒险」可读取。

离线模式：未配置 API Key 时仍可体验内置剧情。

战斗与运气：遇到敌人时弹出战斗面板，可攻击 / 防御 / 施放技能（耗 8 法力）/ 喝药水 / 逃跑；攻击附带「运气骰」判定，暴击与闪避取决于你的运气属性，另有「🎲 命运骰子」可搏一次扭转战局的机会。

羁绊 · 商店 · 成就：右下「羁绊」查看与同伴（如陆沉）的默契；「商店」花金币强化属性、买药水；「成就」收录 9 枚徽章。默契、金币、等级、成就都会计入结局评级（S/A/B/C）。
